Hãy dùng skill Spring Boot Best Practices để audit project Spring Boot hiện tại.

Yêu cầu:
1. Đọc skill springboot-best-practices đã cài trong Antigravity.
2. Quét source code trong workspace hiện tại.
3. Ưu tiên lỗi BẮT BUỘC trước.
4. Tập trung các domain:
   - Security
   - JPA & Hibernate
   - Testing
   - REST API & Controller
   - Exception Handling
5. Với mỗi lỗi, ghi rõ:
   - File bị lỗi
   - Rule/best practice bị vi phạm
   - Mức độ nghiêm trọng
   - Vì sao nguy hiểm
   - Cách sửa đề xuất
6. Chỉ tạo báo cáo audit trước, chưa sửa code.
