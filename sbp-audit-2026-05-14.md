## 🚀 Đề Xuất 3 Việc Nên Làm Tiếp Theo (Phase 2)

Dự án hiện tại rất vững vàng, những công việc tiếp theo nên tập trung vào độ ổn định môi trường và testing mức độ cao hơn:

### 1. Xây dựng Integration Tests (Testcontainers)
- **Hiện trạng:** Đã có Unit Tests (Mock), nhưng chưa có bài test tích hợp nào cho Database (MySQL/PostgreSQL) và Redis thực sự.
- **Action:** Dùng `@SpringBootTest` kết hợp `Testcontainers` để boot các container DB thật lên trong quá trình test, đảm bảo native queries, JOIN FETCH và schema database chạy đúng.

### 2. Tích hợp Monitoring & Metrics (Spring Boot Actuator + Prometheus)
- **Hiện trạng:** Ứng dụng có ghi log ra console nhưng chưa có dashboard quan sát tài nguyên CPU, Ram, Connection Pool hay lượng HTTP Requests.
- **Action:** Mở endpoint `/actuator/prometheus`, cấu hình Prometheus scrape metrics và dùng Grafana để trực quan hóa (tạo dashboard theo dõi memory leak và API latency).

### 3. Tự động hóa CI/CD Pipeline
- **Hiện trạng:** Việc chạy test và build hiện tại đang được thực thi thủ công (thông qua lệnh `mvn clean test`).
- **Action:** Tạo file cấu hình GitHub Actions (`.github/workflows/maven.yml`) hoặc GitLab CI để tự động chạy `mvn clean verify` và báo lỗi ngay trên Pull Request nếu Unit test rớt hoặc build fail.
